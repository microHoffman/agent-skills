# tanstack-query-angular skill

Angular-specific TanStack Query skill for building, refactoring, and reviewing server-state code with
`@tanstack/angular-query-experimental`.

The skill is stored as a standalone directory inside the `agent-skills`
collection, so it can be installed through the Skills CLI:

```bash
npx skills add https://github.com/microHoffman/agent-skills --skill tanstack-query-angular
```

When changing the skill, rerun the eval prompts in `evals/evals.json`.
